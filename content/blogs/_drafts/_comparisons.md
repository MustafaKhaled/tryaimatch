# Comparison-post outlines (5 highest-intent vs-queries)

Comparison posts are gold for SEO: searchers are ~90% ready to buy. They want a definitive verdict — not a both-sides dance.

Each outline follows the same template. Write each as ~1,200–1,600 words. Lighter than pillar posts but higher conversion rate.

---

## 1. Claude Code vs Cursor vs GitHub Copilot

**Target**: `claude code vs cursor`, `cursor vs copilot`, `claude code vs copilot`
**Slug**: `claude-code-vs-cursor-vs-copilot`

**Intent**: Developers picking their primary AI coding tool. Highest commercial value of all comparisons.

**Structure**:
- TL;DR verdict in 60 words: "Claude Code for agentic end-to-end work. Cursor for in-editor editing. Copilot for JetBrains + cheapest entry."
- Side-by-side feature table (use scores from /data/categories/code.ts)
- "Who wins for X" sections:
  - Building full apps → Claude Code
  - Multi-file refactors → Cursor
  - JetBrains shop → Copilot
  - Cheapest paid plan → Copilot ($10/mo)
  - Free tier needed → Cursor or Copilot (Claude Code has no free)
- Real-world scenarios
- FAQ
- Quiz CTA

**Outbound**: each tool's site. **Internal**: pillar post.

## 2. HeyGen vs Synthesia

**Target**: `heygen vs synthesia`
**Slug**: `heygen-vs-synthesia`

**Intent**: Picking between the two avatar video tools. Searched a lot.

**Structure**:
- TL;DR: "HeyGen wins for short-form social. Synthesia wins for corporate training."
- Avatar quality compared
- Language coverage (HeyGen ~40, Synthesia ~140)
- Pricing tier comparison
- "Who wins for X":
  - YouTube content → HeyGen
  - L&D / corporate → Synthesia
  - Solo creator → HeyGen
  - Enterprise → Synthesia
- FAQ + Quiz CTA

## 3. Midjourney vs DALL-E vs Firefly

**Target**: `midjourney vs dalle`, `midjourney vs firefly`, `dalle vs firefly`
**Slug**: `midjourney-vs-dalle-vs-firefly`

**Intent**: Image generator buyer comparing the big three.

**Structure**:
- TL;DR: "Midjourney for quality. Firefly for commercial license. DALL-E for prompt accuracy."
- Output samples (you'll need to generate or describe — DON'T copy from elsewhere, copyright)
- Commercial license breakdown — most underrated factor
- Pricing
- "Who wins for X":
  - Best raw quality → Midjourney
  - Commercial safety → Firefly
  - Prompt-following → DALL-E
  - Free tier → Firefly or DALL-E (via ChatGPT free)
- FAQ + Quiz CTA

## 4. ChatGPT vs Claude (for writing)

**Target**: `chatgpt vs claude for writing`, `claude vs chatgpt`
**Slug**: `chatgpt-vs-claude-for-writing`

**Intent**: Writers picking their daily-driver LLM.

**Structure**:
- TL;DR: "Claude is more consistent for long-form. ChatGPT is faster and has more integrations."
- Side-by-side on 6 dimensions: long-form, marketing copy, editing, code, voice consistency, speed
- Context window: Claude 200k vs ChatGPT 128k → why this matters for long docs
- Pricing
- "Who wins for X":
  - Blog posts > 2000 words → Claude
  - Quick marketing copy → ChatGPT (faster)
  - Brand voice consistency → Claude
  - Image generation included → ChatGPT (DALL-E 3 inside)
- FAQ + Quiz CTA

## 5. n8n vs Zapier

**Target**: `n8n vs zapier`, `zapier alternative`
**Slug**: `n8n-vs-zapier`

**Intent**: Automation buyers, mostly leaning open-source or budget-conscious.

**Structure**:
- TL;DR: "Zapier wins for ease + integrations. n8n wins for power, AI agents, and self-hosting."
- Integration count
- Self-hosting (n8n yes, Zapier no)
- AI agent capabilities (n8n native, Zapier added later)
- Pricing per task / per operation
- "Who wins for X":
  - 5 apps + simple triggers → Zapier
  - Complex multi-step logic → n8n
  - AI agents → n8n
  - Self-host for data sovereignty → n8n
  - Need WhatsApp/Slack/Notion connected in 5 min → Zapier
- FAQ + Quiz CTA

## Common elements all comparison posts need

- Frontmatter (title under 60 chars including "vs", description under 160)
- Open with the verdict — don't bury it
- Comparison table near the top (great for featured snippets)
- "Who wins for [scenario]" sections — these are what people skim
- FAQ block at the end
- Internal link to the matching pillar post
- Quiz CTA at end
- Outbound links to both tools (build "compare" trust by linking to both fairly)
